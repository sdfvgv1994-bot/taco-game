# 俄羅斯方塊對戰

```bash
python tetris/tetris.py
```

選單：`1`~`3` 對電腦（簡單 / 普通 / 困難），`4` 雙人對戰（同一台電腦）。

| 動作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 左 / 右移動 | A / D | ← / → |
| 軟降 | S | ↓ |
| 順時針 / 逆時針轉 | W / Q | ↑ / `/` |
| 硬降 | 空白鍵 | Enter |
| 暫存 | 左 Shift | 右 Shift |

其他：P 暫停、Esc 回選單 / 離開。對電腦時兩組按鍵都能用。

## 對戰規則
- 消行會把垃圾行送給對手：單行 0、雙行 1、三行 2、四行 4
- T 轉（T 方塊旋轉卡入、四個斜角佔三個以上）消 1／2／3 行送 2／4／6，T 轉與連續四行連做再 +1
- 連擊（combo）有加成；連續兩次四行再 +1；全清再 +6，並閃一陣綠光
- 自己消行會先抵銷對方送來的垃圾（板子左側紅條是待落下的垃圾）
- 沒消行就落地時，垃圾行才會從下面頂上來（每次最多 8 行）
- 先被頂到頂的人輸；兩邊方塊順序相同，比較公平
- 電腦難度只差在操作速度：簡單 0.40 秒、普通 0.18 秒、困難 0.07 秒一個動作
