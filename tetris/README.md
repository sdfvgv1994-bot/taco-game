# 俄羅斯方塊對戰

```bash
python tetris/tetris.py
```

仿 Facebook 上《Tetris Battle》的玩法。選單 `1`~`6` 選模式，對電腦的模式再選難度（`1` 簡單、`2` 普通、`3` 困難；有些模式 `4` 是雙人同機）。

| 模式 | 說明 |
| --- | --- |
| 1 Battle 2P | 限時 2 分鐘。被頂到頂 = 對手 +1 KO，清空場地繼續。時間到依 **KO > 送出行數 > 行高** 判勝負 |
| 2 Battle 6P | 你 vs 5 個電腦，右側是小板子。有人 10 KO 或 2 分鐘到就結束，依同樣規則排名 |
| 3 Sprint | 單人，消 40 行比時間，最快時間會存起來 |
| 4 Sprint 4P | 和 3 個電腦比誰先消完 40 行（不互相攻擊） |
| 5 Marathon | 單人 15 關，每關消 10 行，越來越快；頂到頂就結束，會記錄最多消行數 |
| 6 生死戰 | 2 人，先被頂到頂的人輸 |

多人對戰時，垃圾行送給你**鎖定的目標**（小板子上的藍色準星）。按 Tab / T 輪流換目標，或用滑鼠直接點小板子。

| 動作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 左 / 右移動 | A / D | ← / → |
| 軟降 | S | ↓ |
| 順時針 / 逆時針轉 | W / Q | ↑ / `/` |
| 硬降 | 空白鍵 | Enter |
| 暫存 | 左 Shift | 右 Shift |

其他：P 暫停、Tab / T 換目標、M 音效 / 音樂開關、Esc 回選單 / 離開。對電腦時兩組按鍵都能用。

## 對戰規則
- 消行會把垃圾行送給對手：單行 0、雙行 1、三行 2、四行 4
- T 轉（T 方塊旋轉卡入、四個斜角佔三個以上）消 1／2／3 行送 2／4／6，T 轉與連續四行連做再 +1
- 連擊（combo）有加成；連續兩次四行再 +1；全清再 +6，並閃一陣綠光
- 自己消行會先抵銷對方送來的垃圾（板子左側紅條是待落下的垃圾）
- 沒消行就落地時，垃圾行才會從下面頂上來（每次最多 8 行）
- 先被頂到頂的人輸；兩邊方塊順序相同，比較公平
- 電腦難度只差在操作速度：簡單 0.40 秒、普通 0.18 秒、困難 0.07 秒一個動作

## 音效與音樂
- 移動、旋轉、暫存、硬降、落地、各種消行、T 轉、全清、被攻擊、輸贏、倒數都有音效
- 背景音樂是 Korobeiniki（俄羅斯民謠，Tetris 主題）
- 全部由程式即時合成（`sound.py`），沒有音檔；啟動時在背景合成，約一兩秒後才會有聲音
- 沒有音效裝置時自動靜音，不影響遊戲
